# Hu Tan 0.2.1-beta

بوت Messenger عربي Modular — المطور: **Rin Il**.

## التشغيل في Termux

```bash
git clone <رابط-المستودع>
cd Hu-Tan
npm install
npm start
```

في أول تشغيل سيظهر معالج الإعداد. يطلب:

- مسار AppState المحلي.
- ID الغروب المسموح.
- ID المالك الإداري اختياريًا.
- رابط AI ومفتاحه اختياريًا.
- إعدادات الترحيب ورسالة البدء.

يُحفظ AppState داخل `data/appstate.json` ولا يجب رفعه إلى GitHub.

## الوظائف

الأوامر Modular، نظام إدارة، ترحيب، XP وRank، اقتصاد وبنك وتحويلات وسجل معاملات، مهام يومية، ألعاب، عداد رسائل، AI مع Reply TTL، Anti-Spam وCooldown، وقاعدة بيانات محلية بحفظ ذري.

البوت مقيد بغروب واحد عبر `facebook.allowedThreadID`، ويتجاهل الأحداث من أي غروب آخر.

## الاختبارات

```bash
npm test
```

الاختبار يشمل Syntax، تحميل الأوامر والتعارضات، الاقتصاد، المهام، Reply TTL، وإعدادات الغروب ووجود الأحداث.

## الأمان

لا ترفعي الملفات التالية إلى GitHub:

```text
config/config.json
data/appstate.json
data/database.json
.env
```

واجهة Messenger المستخدمة غير رسمية وتعتمد على جلسة حساب. لا توجد ضمانة لمنع تقييد الحساب من Meta؛ تقليل النشاط غير الضروري وحصر البوت في غروب واحد لا يلغي مخاطر المنصة.
