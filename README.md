# Hu Tan 0.2.0-beta

Hu Tan هو بوت Messenger عربي Modular، المطور: Rin Il.

## التشغيل في Termux

```bash
git clone <رابط-المستودع>
cd Hu-Tan
npm install
npm start
```

في أول تشغيل يفتح معالج الإعداد داخل Termux لإدخال AppState وID الغروب وإعداد AI. لا تضعي AppState أو مفاتيح API داخل GitHub.

## النظام

البادئة الوحيدة: `.`

Hu Tan يعمل على غروب واحد محدد في `allowedThreadID`، ويتجاهل الأحداث القادمة من أي غروب آخر.

المكونات الأساسية: أوامر Modular، أحداث ترحيب، XP وRank، مهام يومية، اقتصاد وبنك وتحويلات وسجل معاملات، ألعاب عربية، AI مع Reply TTL، صلاحيات إدارة، Anti-Spam، حفظ ذري لقاعدة البيانات، وسجلات تشغيل.

## أوامر الإدارة الأساسية

`.إحصائيات` — إحصائيات الغروب

`.تحذير` — بالرد أو المنشن

`.تحذير_مسح` — تصفير التحذيرات

`.طرد` — إخراج عضوة غير مشرفة

`.وضع_الهدوء تشغيل`

`.الترحيب تشغيل`

## الاختبارات

```bash
npm test
```

`npm test` يفحص Syntax ثم يشغّل Smoke Test على الأوامر والاقتصاد والمهام وCooldown وعدم وجود فئات أوامر فارغة.

## ملاحظة المنصة

هذا المشروع يستخدم واجهة Messenger غير رسمية تعتمد على AppState. لا توجد ضمانة لعدم تقييد الحساب من Meta؛ أفضل تقليل للمخاطر هنا هو حصر البوت بغروب واحد وتقليل الرسائل التلقائية وتجنب الإرسال الكثيف.
